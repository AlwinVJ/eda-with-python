# Routes

TanStack Start uses **file-based routing**. Every `.tsx` file in this directory
defines a route. The core portfolio experience consists of:

| File                 | URL               | Description                                                   |
| -------------------- | ----------------- | ------------------------------------------------------------- |
| `index.tsx`          | `/`               | Home page showcase and featured projects                      |
| `projects.index.tsx` | `/projects`       | Full projects catalog grouped by focus area                   |
| `projects.$slug.tsx` | `/projects/:slug` | Dynamic project detail page (metadata & deep-dive case study) |
| `__root.tsx`         | App Shell         | App shell — wraps every page; theme, layout & 404             |

`routeTree.gen.ts` is auto-generated by TanStack Start / Router. Don't edit it by hand.
