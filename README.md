A comprehensive, step-by-step platform for learning **Exploratory Data Analysis (EDA)** through structured lessons, carefully curated datasets, practical examples, and real-world projects. InsightPy is designed to help learners build strong data analysis skills by following an end-to-end EDA workflow—from understanding a dataset to generating actionable insights.

## Features

* Structured EDA learning roadmap
* Carefully categorized datasets for practice
* Guided data preprocessing techniques
* Statistical analysis and data visualization
* Real-world EDA case studies
* Interactive and responsive user interface
* Dark and light mode support
* Project-based learning approach

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui

## Getting Started

### Prerequisites

Ensure the following are installed:

* Node.js (v18 or later recommended)
* npm

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd <repository-name>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL displayed in your terminal.
